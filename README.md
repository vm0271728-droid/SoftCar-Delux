# SoftCar Delux Rebuild

Новая ветка развития проекта на Godot + C++.

Цель: переработка игры с новой графикой, физикой автомобилей и системой повреждений.

## Структура

- `godot/` — игровой проект Godot
- `cpp/` — нативные модули и игровые системы
- `docs/` — документация проекта
- `assets/` — игровые ресурсы
